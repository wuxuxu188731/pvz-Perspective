# 植物大战僵尸「透视自瞄」整活

视频中的方框、射线和白圈是额外绘制在游戏上方的覆盖层，白圈没有自瞄功能。“环境异常、被踢下线”也是为视频制作的假弹窗，并非真的封号。结尾只是画面定格，游戏仍在后台运行。

源码免费公开，欢迎任何人使用、修改、二创和再分发，无需付费或加入 Telegram 频道。此授权仅限本项目原创绘制源码，不包含游戏本体及素材。

源码地址：[GitHub](https://github.com/wuxuxu188731/-)。

## 怎么用

1. 自行准备植物大战僵尸杂交版 v2.0，运行游戏目录中的 `PlantsVsZombies.exe`（也可通过 `pvzHE-Launcher.exe` 启动），进入关卡。
2. 运行 `pvz-esp/bin/Overlay.exe`，切回游戏即可看到绘制。其他版本尚未验证。
3. 开始录屏后，在游戏窗口按 **F10** 启动或重播表演：前 15 秒正常，随后方框闪烁、乱跳，约 22 秒弹出提示框。
4. 按 **F11** 关闭表演、恢复正常绘制；弹窗上的“确定”也能恢复。
5. **F8** 显示/隐藏绘制，**F9** 完全退出绘制程序。切出游戏或隐藏绘制时，表演计时暂停。

如果没有 `Overlay.exe`，在项目根目录用 PowerShell 运行 `powershell -ExecutionPolicy Bypass -File .\pvz-esp\src\build.ps1` 编译。

录屏选择“屏幕/显示器捕获”，确保能录到覆盖层。
